## ici 0.14.1 — wheel ZIP 판독 보안 수정

0.14.0 archive에 들어 있던 `zip` crate 8.6.0을 9.5.1로 올린 보안 patch release입니다. 명령·설정·결과 계약과 배포물
구성은 0.14.0과 같습니다.

### 보안

- `ici-analysis`의 wheel artifact 검사가 쓰는 `zip` crate 갱신(GHSA-m665-v7pm-7grj, GHSA-q7v9-x93c-xqv3,
  GHSA-hjqx-j4rw-g7xv, GHSA-9hj8-73fh-9963, GHSA-8hxf-qr8p-62x4).
- ici와 관련된 항목은 GHSA-m665(local header와 central directory 불일치)입니다. 조작된 wheel이면 ici의 digest·`RECORD`
  검사가 installer와 다른 bytes를 볼 가능성이 있었습니다. ici에서 파일 쓰기나 코드 실행이 일어나는 경로는 확인되지
  않았습니다. ici는 wheel을 풀어 쓰지 않고 symlink·특수 member를 거부하며 AES·legacy decoder 기능을 켜지 않습니다.

### 업데이트

- `ici-0.14.1-x86_64-unknown-linux-musl.tar.gz`와 `.sha256`을 받아 `install-native.sh --archive … --sha256 …` 또는
  `ici setup --archive … --sha256 …`으로 설치합니다. `ici setup --rollback`으로 이전 선택을 되돌릴 수 있습니다.
