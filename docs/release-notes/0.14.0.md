## ici 0.14.0 — Rust native 단일 제품

ici는 이 버전부터 Rust native 단일 제품입니다([ADR-0008](https://github.com/jihoon22-lee/ici/blob/v0.14.0/docs/design/ici-next/adr/0008-rust-native-replacement.md)).
명령·설정·결과 계약(`ici verify`, 엔진별 명령, `ici analyze`/`report`/`diff`, `[ici]`/`[engines]`·`[workspace]`·
`schema_version = 2`, `ici.result/v3`, `ici.next.run` v2, `ici.next.event` v1, `ici.auxiliary` v1)은 v0.13.0과 같습니다.
기능별 동등성과 의도한 차이는 [이전 대응표](https://github.com/jihoon22-lee/ici/blob/v0.14.0/docs/design/rust-replacement/inventory.md)에 있습니다.

### 주요 변경

- **배포물**: `ici-0.14.0-x86_64-unknown-linux-musl.tar.gz` — 정적 `bin/ici`, 검증된 native Ruff/ty, 모든 라이선스 고지.
  Python 인터프리터·pyz·wheel·Python 모듈은 들어 있지 않습니다. 이 bytes는 exact-main candidate와 같습니다
  (두 독립 build byte 동일, release 검사·배포 artifact corpus·Quality Zoo native 인수 통과).
- **더 이상 발행하지 않음**: `ici.pyz`, Python wheel/sdist, pyz self-report. 과거 공개판과 tag는 그대로입니다.
- **viewer**: `icirv`(Qt 없는 정적 CLI), `icirv-gui`(Qt 6 개발 환경용)와 `viewer-assets.sha256`.
- **설치**: `install-native.sh`·`ici setup`은 root 없이 XDG 경로에 설치하고 `ici setup --rollback`으로 되돌립니다.
  시스템/사설 CA와 proxy 설정을 따릅니다.
- **Python의 역할**: ici 자체는 Python 없이 실행됩니다. 프로젝트의 pytest·coverage·mypy는 외부 검사 도구입니다.
- **종료 코드 3**: 필수 증거가 불완전하면 legacy `ici verify`와 엔진 명령도 3으로 끝납니다(v0.13.0은 1).
- **결과·cache**: 새 결과와 cache는 `.ici/rust-v1/`에 씁니다. 비교 기준 baseline은 native로 새로 만듭니다.
- **지원 범위**: Linux/WSL x86_64(`limited`, 측정한 범위). aarch64·macOS·native Windows는 지원하지 않습니다.
