# Public v0.12.0 release evidence

## Overview

v0.12.0은 공개 stable 릴리스다. [GitHub Release
v0.12.0](https://github.com/jihoon22-lee/ici/releases/tag/v0.12.0)은 exact `main` commit
`65752bc86b49c9845e6282ddaf3c00584e415b60`를 대상으로 게시됐고, provenance·artifact 검증이
모두 완료됐다. 이 문서는 release 근거를 한곳에 고정하고, v0.11.0 evidence는 historical
snapshot으로 남는다.

`release: cut v0.12.0` commit(#284)이 예고한 대로, evidence block의 SHA-256과 run ID는
측정 후인 지금 채운다.

## Context

이번 릴리스는 candidate acceptance가 머지 후에도 한 단계 더 요구됐다 —
`release: cut` 머지 직후 `candidate-quality-zoo` 게이트가
`unsupported-ici`로 실패했다. corpus가 expectation을 artifact SHA-256으로
고르는데 0.12.0 digest가 등록되지 않았기 때문이다. #285에서 16개
시나리오에 `released-v0.12.0.json` 실측 expectation을 바인딩해 해결했고,
그 커밋(`65752bc`)을 태그 대상으로 삼았다.

```text
$ cat ici.pyz.sha256

```

`icirv-gui`의 digest는 v0.11.0과 byte-identical하다 — `viewer/`의 GUI 바이너리
입력이 그대로였기 때문이다. `icirv`(CLI 바이너리)는 바뀌었다.

### Deterministic-build chain

세 지점에서 같은 SHA가 나왔다 — 로컬 `verify-reproducibility.sh` 이중 빌드,
CI candidate artifact(run 37708254797, target `879eecb4`), 공개 release asset.
같은 소스에서 같은 바이트가 나오는 것이 세 번 독립 확인됐고, quality-zoo가
판정한 candidate artifact와 공개된 asset이 같은 파일임이 digest로 증명됐다.
