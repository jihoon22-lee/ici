# ici v0.10.2 corrective release preparation

## Outcome

This release candidate advances only the patch component, from `0.10.1` to `0.10.2`. It does not
claim a new roadmap checkpoint. The patch is justified by defects reproduced against the public
v0.10.1 boundary while BuildScope exercised real Qt 5 and Qt 6 projects on Ubuntu 24.04.

## Included corrections

- Preserve bounded, validated external Qt macro previews while exporting their location as
  `[external]`.
- Preserve bounded CTest sanitizer classification without copying raw stacks or host paths.
- Keep nonzero clazy output atomic and fail-closed while retaining a safe diagnostic count summary.
- Make clang-tidy and clazy follow the exact GCC selected by the compilation database, including
  ordered libstdc++ roots on hosts with more than one installed GCC version.

No ordinary feature, test, refactor, or documentation PR caused this version change. The next minor
release remains deferred until the maintainability and C++ safety checkpoints and their real
toy/known-answer validation are complete.

## Release boundary

The version surfaces and changelog are prepared on a separate branch. An annotated `v0.10.2` tag
must point to the eventual exact green main commit after this release-prep PR merges. The release is
complete only after provenance succeeds and all nine public assets independently match their API
sizes and SHA-256 digests; until then, `0.10.2` remains a candidate rather than a stable release.
