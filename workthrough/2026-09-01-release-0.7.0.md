# ici 0.7.0 Release

## Overview

`0.6.0` 이후 main에서 완료한 finding/report 계약, toolchain·pipeline·cache 기반 구조와
compiler-exact CMake/qmake compilation context를 첫 외부 소비 가능 릴리스로 묶는다. BuildScope가
내부 소스 checkout에 의존하지 않고 이 릴리스 산출물을 사용해 target별 실제 compile 설정을
대조할 수 있게 하는 교차 저장소 경계이기도 하다.

## Changes Made

- `src/ici/__init__.py`와 repository `ici.toml`의 버전을 `0.7.0`으로 동기화했다.
- 기존 `Unreleased` 변경 기록을 `2026-09-01`의 `0.7.0` 섹션으로 확정하고 새
  `Unreleased` 섹션을 유지했다.
- 코드 기능은 릴리스 커밋에서 추가하지 않는다. 이 PR은 이미 개별 PR과 전체 gate로 검증된
  I1~I3 구현의 버전·변경 기록 경계만 만든다.

## Verification Results

- Python 3.10 전체 pytest는 1,275개 테스트를 49.00초에 통과했다.
- Ruff check와 142개 파일 format check가 통과했다.
- 두 번의 pyz 빌드는 모두 2,151,980 bytes와 SHA-256
  `8f0d217d2bd810478c822bdccbe5642efd1d8b34c8dbfe66e063b1845ef8e8d5`를 만들어 재현성을
  확인했다. 10개 배포판은 전부 `py3-none-any`이고 `certifi`는 포함되지 않았다.
- smoke는 `ici 0.7.0`, Python 3.10 직접 실행, `dist/ici`/`dist/ici.pyz` 동일성과 Zero-CDN
  HTML을 포함한 모든 검사를 통과했다.

## Remote Verification Plan

- PR의 Verify & Dogfood, Qt5/Qt6 viewer, sticky comment/Pages와 Merge Gate를 모두 확인한다.
- squash merge 뒤 exact main commit의 Merge Gate가 성공한 다음에만 `v0.7.0` tag를 만든다.
- release workflow의 provenance, build/test, checksums, `ici.pyz --version`, release assets와
  게시된 self/viewer reports를 독립 확인한다.

## First Release Attempt and Remediation

Tag `v0.7.0`의 첫 workflow run `33415212915`는 provenance, 1,275 tests, build, smoke,
dogfood와 static viewer를 통과했지만 GUI asset 단계에서 실패해 release를 만들지 않았다.
workflow가 `icirv-gui` target만 빌드한 뒤 전체 CTest 7개를 실행해, 등록된 core/CLI/GUI test
executable이 하나도 존재하지 않았고 모두 `Not Run`(exit 8)이 됐다. 릴리스 gate를 약화하지
않고 configured viewer graph 전체를 빌드하도록 수정하며, 회귀 테스트가 target-only build의
재도입을 막는다. 수정 PR과 새 exact-main Merge Gate가 성공한 뒤 게시되지 않은 실패 태그를
그 새 커밋으로 재생성한다.

## Follow-up

BuildScope B0/B1은 공개 `v0.7.0` asset과 checksum을 pin해 ici I3의 CMake/qmake compilation
context를 실제 외부 hybrid project에서 검증한다. 그 대조가 끝날 때까지 I3 전체 상태는
pending이다.
